### Connecter 处理

根因：第三方插件放在安装版 `Engine/Plugins/`，`EnabledByDefault: true` 时 UBT 在只读 `UE5Rules.dll` 中查找 `ConnecterUEPlugin`。该 DLL 是 Epic 出包产物（清单为 `D:\build\++UE5\Sync\...`），不含 Connecter，且 `File is installed` 不会重编。`Build.cs` 类定义本身正确。插件目录只有 `Build.cs` + 预编译 DLL，没有 C++ 源。

已执行：

- 工程禁用：`PBRTextureLabHost.uproject` 中 `ConnecterUEPlugin.Enabled = false`
- 引擎描述：5.6 / 5.7 `ConnecterUEPlugin.uplugin` 改为 `EnabledByDefault: false`（与 5.8 一致）

未执行（当前会话权限不允许改 Program Files 下的引擎插件树）：

- 将 `Engine/Plugins/Connecter` 挪到 `Engine/Plugins/Marketplace/Connecter`
- 在启用状态下重编 5.7 验证 `MarketplaceRules.dll`

手动迁移（需对引擎安装目录有写权限的终端）：

```powershell
foreach ($ver in @('UE_5.6','UE_5.7','UE_5.8')) {
  $src = "C:\Program Files\Epic Games\$ver\Engine\Plugins\Connecter"
  $dst = "C:\Program Files\Epic Games\$ver\Engine\Plugins\Marketplace\Connecter"
  if ((Test-Path $src) -and -not (Test-Path $dst)) {
    Move-Item -LiteralPath $src -Destination $dst
  }
}
```

迁移后再把 `.uproject` 临时改成 `Enabled: true`，用 5.7 的 `Build.bat` 编一次。通过后应把本工程改回 `Enabled: false`，避免 PBRTextureLab 依赖 Connecter。
